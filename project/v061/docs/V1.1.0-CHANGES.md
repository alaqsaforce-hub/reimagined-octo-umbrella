# v1.1.0 — "always an agent, and it answers out loud"

Four of the five things you asked for land in this build. The fifth (the big integration list) is mapped
release by release in `ROADMAP-v1.2-to-v1.4.md`, because each integration needs its own permission,
credential and verification — claiming them all in one version would be a lie.

---

## ১. সবসময় এজেন্ট মোডে, কম ব্যাটারিতে (always-on agent, cheap)

* `AssistantMode.AGENT` is now the default mode.
* The wake-word service keeps listening, but **the gap between listening cycles is a policy, not a constant**
  (`hotword/DutyPlanner.kt`, pure):

| Situation | Gap between cycles | Mic open roughly |
|---|---|---|
| Charging | 0.3 s | ~continuous |
| Screen on | 0.5 s (0.7 s lean) | ~continuous |
| **Screen off, always-on, lean** | **9 s** | **~10 %** |
| Screen off, always-on, lean off | 1.5 s | ~40 % |
| Screen off, always-on off | 5 s (just checking the screen) | 0 % |

* The settings screen prints the rhythm your phone is using right now, plus live counters
  (`N listen cycles · M wake hits`) so "is it really running?" is answerable.
* Honest trade-off, stated in the UI: with the lean gap a wake word can arrive up to ~9 s late.
* `text-only` mode closes the microphone completely (hotword and dictation both refuse to open it).

## ২. ডাকলে বাবল + কথা বলা, লোকাল মডেল, প্রোভাইডার টেস্ট (voice out, local models, provider test)

* **Wake → it speaks.** `"শাহরুখ"` → bubble + a short "বলুন" (TTS), then listening. Spoken results follow
  the mode; calls, TTS-already intents and read-aloud are excluded so nothing is said twice or into a call.
* **Local models** (Settings → সিস্টেম ও এজেন্ট → লোকাল মডেল): Ollama / llama.cpp / LM Studio on the phone
  or on a computer in the same Wi-Fi, connected through the existing *Custom (OpenAI-compatible)* provider
  (`http://192.168.x.x:11434/v1`). Recommended small models, with RAM: **qwen2.5:1.5b** (≈1 GB, fast) ·
  **gemma2:2b** (≈2 GB) · **llama3.2:3b** (≈3 GB, smarter). On 4 GB phones 1.5B is the safe pick. Whisper
  (speech-in) is already on the device.
* **Provider self-test** (new): one cheap authenticated `/models` call per provider — ChatGPT (OAuth
  sign-in), Gemini, OpenRouter, Groq, Mistral, OpenAI, Anthropic, DeepSeek, and the custom/local endpoint —
  reported per provider as **✓ working / ✗ failed / ⛔ blocked / ○ not configured**, with the real reason
  (e.g. `401 unauthorized`, `paid only`, `local-only mode`). No tokens are spent, and nothing is called
  "working" because a key merely exists.

## ৩. চারটি মোড (four modes)

| Mode | Mic | Answers | Screen |
|---|---|---|---|
| **এজেন্ট (Agent)** | on (when the wake word is enabled) | spoken | text + speech, may run a plan |
| **ভয়েস → ভয়েস** | on | spoken | transcript secondary |
| **ভয়েস + লেখা** | on | written **and** spoken | both |
| **শুধু লেখা (Text only)** | **closed** | written only | text |

One switch (Settings → মোড) drives everything: hotword, dictation, TTS, undo chip, wake behaviour
(`AssistantModeCore`, pure + tested).

## ৪. পারমিশন ও সিস্টেম নিয়ন্ত্রণ — দিয়ে, তারপর যাচাই (grant, then verify)

Settings → সিস্টেম ও এজেন্ট lists every capability with **what it unlocks**, a *grant* button, and a
**টেস্ট** button that really exercises it:

| Capability | What the test actually does |
|---|---|
| Bubble / overlay | starts the assistant service and asks you to look at the screen |
| Accessibility | checks the service is *connected* (not merely enabled — the common silent failure) |
| Notification access | counts stored notifications **and** visible media sessions |
| Microphone | permission **and** `SpeechRecognizer.isRecognitionAvailable` |
| Calls & contacts | counts readable contacts **and** checks the answer permission |
| Wake word | reports the service state plus cycles/wakes |
| TTS | speaks a test sentence and reports whether a voice exists |
| Digital assistant | checks the role is held |
| Battery exemption | reads the real exemption state |

Plus the **skills list** (`Skills`, 24 rows): ✓ what works in this build, ○ what is planned and for which
version — so "it can do X" is always checkable.

## ৫. বড় ইন্টিগ্রেশনগুলো — পরিকল্পনা ও আজকের অবস্থা

Implemented now: calls (incl. WhatsApp calls via the ringing notification), messages (digest, read-aloud,
direct reply), media/YouTube navigation (play/pause/next through whatever player is active — YouTube
included), apps, screen reading and tapping (accessibility), memory, knowledge base, GitHub, Gmail/IMAP,
Drive, local model, internet-free operation.

Not yet — with the release each one is planned for, and why it needs that much: see
`ROADMAP-v1.2-to-v1.4.md` (scheduled messages & reminders, YouTube search, WhatsApp/Facebook/Instagram
summaries, YouTube-link summaries, Calendar, MCP client, VPS/SSH).
