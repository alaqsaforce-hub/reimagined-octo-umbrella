# VoiceDock AI v1.2.0 — "providers that work, permissions that are real, and the first scheduled job"

**versionCode 20 · versionName 1.2.0 · minSdk 26 · target 35** · built 2026-11-01

This release answers the two hard requirements of the last message — *a local model or provider must not fail*
and *device permissions must actually be in effect* — and adds the first item of the integration roadmap
(reminders / scheduled jobs).

---

## 1. A local model or provider must not fail

Seven separate causes of "the AI is broken" were reproduced and closed. None of them needed a new model.

| Cause (what a user sees) | What was happening | v1.2.0 |
|---|---|---|
| `192.168.0.5:11434` → "invalid URL" | the app demanded a scheme | bare `host:port` gets `http://` + `/v1` automatically |
| pasted `…:11434/api/tags` from a curl command → 404 | the client appends its own path | known endpoint paths are trimmed (`/api`, `/api/tags`, `/chat/completions`, `/v1/models`, …) |
| "…/v1" left off → 404 | same | `/v1` is appended when the path is empty; a custom proxy path is left alone |
| first token takes 90 s on a laptop CPU → "no internet" | 60 s read timeout, and every socket timeout was classed as NETWORK | self-hosted servers use a 300 s read timeout, and a socket timeout has its own kind (`TIMEOUT`) with its own sentence |
| one Wi-Fi hiccup / one 502 → the only provider is written off | the router moved on immediately | `RetryPolicy`: one retry per transient failure (400 ms, then 1.2 s), short `Retry-After` honoured, auth/limit/content never retried |
| "connected ✓" from a server with no models installed | `/models` answering was treated as healthy | a local server with zero models is **FAILED** with `ollama pull qwen2.5:1.5b` as the fix |
| an embedding/vision model chosen first → chat fails | model list was sorted alphabetically | `LocalServer.rank` prefers chat/instruct families and sinks embed/whisper/guard/OCR models |

Every failure on a self-hosted server now ends in one actionable Bengali sentence
(`LocalServer.diagnose`): *server not running / not on the same Wi-Fi / model too big / wrong port /
credentials not needed / no model installed*. `AiSetup.explainFor` picks that sentence only for a
self-hosted provider; cloud providers keep their own wording.

**Unchanged on purpose:** an `http://` address that is not on the LAN is still refused
(`insecure_url`), userinfo/query/fragment URLs are still rejected, and a local request still does not
follow redirects. The normaliser only removes dead ends — it never weakens the policy.

## 2. Permissions that are genuinely in effect

The old Settings section was a hand-written list of nine rows. Hand-written lists drift, so this version
starts from a **catalog** (`permissions/PermissionCatalog.kt`) of all 21 accesses the app declares:

* each row says *what it unlocks*, in Bengali and English;
* `PermissionProbe` asks the OS **right now** — accessibility is "connected", not just "enabled"; the
  assistant role is really held; the exact-alarm access is really granted;
* **সব অনুমতি একসাথে** requests every missing runtime permission in a single dialog;
* a feature is only "usable" when *all* of its accesses are granted (`PermissionGate`), and the header
  names the first thing to fix — a wall of ✗ helps nobody;
* **the gap is now a failing test**: `PermissionCatalogTest` parses `AndroidManifest.xml` and fails if a
  declared permission is unclassified, or if a catalog row claims a permission that is not declared.

New in the catalog for this release: `SCHEDULE_EXACT_ALARM` (+ a request button) and
`RECEIVE_BOOT_COMPLETED`.

## 3. Scheduled jobs — reminders (first kind)

Speak it, and it is stored and armed:

* **৩টায় মনে করিয়ে দাও পানি খেতে** · **কাল সকাল ৯টায় মনে করিয়ে দাও** · **সন্ধ্যা ৭টায় …** ·
  **২০ মিনিট পরে …** · **remind me to call Rahim in 20 minutes** ·
  **রিমাইন্ডার দেখাও** (list) · **আমার রিমাইন্ডার বাতিল করো** (cancel from Settings)
* `TimeWords` is a real time grammar, not a regex on "টা": Bengali digits, ভোর/সকাল/দুপুর/বিকাল/সন্ধ্যা/রাত,
  আজ/কাল/পরশু, am/pm, `9:30`, relative minutes/hours/seconds — with the two traps closed
  (রাত ১২টা = midnight, দুপুর ১২টা = noon) and **a bare "৩টায়" meaning the next 3 o'clock**, never the past.
* A reminder is a **Room row (schema v4, explicit migration 3→4)** plus an `AlarmManager` alarm. The row is
  the truth: pending reminders are re-armed after a reboot (`BootReceiver`), and a missed alarm still shows
  in Settings instead of disappearing.
* Notification with **হয়ে গেছে ✓** and **১০ মিনিট পরে**; finished rows are pruned after a week.
* **Honest about exactness:** Android 12+ needs a special access for exact alarms. Without it the alarm
  still fires (`setAndAllowWhileIdle`) and *the answer and the list say* "কয়েক মিনিট দেরি হতে পারে",
  instead of promising a minute-precision it does not have.

## 4. What this version does **not** do

* **Scheduled messages** ("রাতে রহিমকে বলো আমি কাল আসব") are **not** in this build. Sending a WhatsApp
  message on a timer without user interaction needs either accessibility automation or a server; shipping
  the entry without a working, honest send path would be a claim the app cannot keep. It is the first item
  of v1.2.1 in `ROADMAP-v1.2-to-v1.4.md`, together with internet search.
* No new cloud provider was added; the work was making the existing nine *work*.
* Calendar, YouTube search/summary, social summaries, MCP, VPS/SSH stay in v1.3/v1.4.
