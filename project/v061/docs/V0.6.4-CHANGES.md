# v0.6.4 — the fix pack: what changed

Base: `project/v061` at v0.6.3 (commit `941193c`). Built and tested on 2026-10-30.
This release is **behaviour-preserving** apart from the two new privacy controls; there are no new
AI features and no new permissions.

## 1. Android 8.0+ works again (regression fix)

- `minSdk` **33 → 26**. v0.6.3 had raised the floor to Android 13 for no code reason — nothing in the
  app needs API 33 to *start*; features that need newer APIs already guard themselves at runtime:
  - per-window screenshot / Explain screen → Android 14+ (`Build.VERSION.SDK_INT < 34` → clear message)
  - on-device speech recogniser → Android 12+ (`SDK_INT >= 31` check)
  - foreground-service types / `specialUse` → Android 14+ (already conditional on `Build.VERSION`)
- Practically every Android 8.0–12 device can now install the app again, which matters far more in
  Bangladesh than the newer-only path did.

## 2. User-maintained probe blocklist (closed P0 privacy item)

The v0.6 handoff listed *"no user-maintained pre-traversal blocklist"* as an open P0 issue. Now:

- **`context/ProbePolicy.kt`** (new, pure/JVM-tested) — normalises, caps (100), dedupes and matches
  package names. Matching is case-insensitive and hierarchical: blocking `com.example.bank` also
  blocks `com.example.bank.wallet`, but **not** `com.example.bankrupt`.
- **`ScreenProbe`** takes `extraBlocked` and checks it **before the accessibility tree is walked** —
  a blocked app's window is never traversed, counted or buffered. No single node is read.
- **`BlockReason.USER_BLOCKED`** (new) gives the bubble an honest explanation ("you blocked this
  app") instead of blaming the built-in finance rules.
- **Settings → ভাসমান সহকারী** now has the blocklist editor: type a package name, or pick from the
  launcher-visible installed apps (no `QUERY_ALL_PACKAGES` needed).

## 3. Local audit counter (closed P0 privacy item)

- **`security/ProbeAudit.kt`** (new) counts *attempts*, *refused* and *used*, plus the timestamp of
  the last attempt. **Counts only** — never a package name, label, window title or screen text, so
  the counter cannot itself leak anything. Stored in app-private SharedPreferences, never uploaded,
  resettable from the UI.
- All four probe call sites now go through one gate, **`device/ProbeRunner.kt`** (new), which reads
  the blocklist, probes, and records the audit row. Direct `ScreenProbe.probe` calls are gone from
  `AssistantOverlayService` and `ScreenAssistant`.

## 4. Much smaller APK — 42.4 → 17.7 MiB

Two effects stacked up:

- `packaging.resources.excludes += "org/bouncycastle/pqc/**"` — bcprov ships post-quantum tables
  (`lowmc` 3.6 MB, `sike/p434`, `p503`, `p610`, `p751`, 8.2 MB raw / 4.1 MB compressed) that only
  matter for PQC algorithms. VoiceDock never uses them (BC is present only as a PDFBox dependency);
  classic crypto and PDF text extraction are untouched.
- Restoring `minSdk = 26` also dropped AGP below the level where it keeps **DEX uncompressed** in the
  APK. The 16 dex files (36 MB of code) were previously stored raw and are now deflated: 36.0 MB →
  14.3 MB. The *download* shrinks by ~25 MB; the installed footprint is similar because Android
  extracts dex on install for older targets anyway.

Measured: `app-debug.apk` 44,419,198 bytes → **18,555,362 bytes**; uncompressed content 51.3 → 43.5 MB.

## 5. Housekeeping

- `versionName 0.6.4`, `versionCode 10`.
- New tests: `ProbePolicyTest` (18 cases) covering normalisation, the cap, dedupe, hierarchical
  matching, the pre-traversal gate and the `USER_BLOCKED` policy contract.
- `docs/PROGRESS.md` finally documents v0.6.1–v0.6.4 (it had stopped at v0.5.0).
- `docs/PRIVACY.md` updated: the two open items above are now implemented and described.
- `docs/TEST-RESULTS-v0.6.4.md` records the first full test run for this line of code.

## Still NOT done (deliberately)

- **No device testing.** Nothing here was run on a phone or emulator. Microphone, overlay,
  accessibility, IME, Whisper, OAuth and the agent remain unverified on hardware.
- `FLAG_SECURE` detection is still heuristic (Android does not expose it to accessibility probes);
  the blocklist is the reliable control, which is exactly why it now exists.
- Release signing is still user-owned; the shipped APK is debug-signed.
