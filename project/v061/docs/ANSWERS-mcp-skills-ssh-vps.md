## ১. "গিটহাব এমসিপি দিয়ে সহকর্মীর মতো কাজ হবে?"

**হ্যাঁ, তবে সেটা GitHub-এর *ক্লাউড কপিতে*, আপনার ফোনে নয়।** GitHub-এর অফিসিয়াল MCP সার্ভার
(`github/github-mcp-server`) যে টুলগুলো দেয় — যাচাই করা তালিকা:

| আপনি যা চাইলেন | কোন টুল | হবে? |
|---|---|---|
| রিপোতে ফাইল লেখা / **কমিট** | `create_or_update_file` (SHA দিয়ে), `push_files` (একাধিক ফাইল, এক কমিটে) | ✅ |
| **পুশ** | `push_files` / `create_or_update_file` সরাসরি ব্রাঞ্চে কমিট করে | ✅ |
| ব্রাঞ্চ তৈরি | `create_branch` | ✅ |
| **PR তৈরি / মার্জ** | `create_pull_request`, `merge_pull_request` (merge/squash/rebase), `update_pull_request_branch` (base-এর সাথে PR ব্রাঞ্চ সিঙ্ক) | ✅ |
| **পুল** | `get_file_contents`, `list_commits`, `compare_commits`, `update_pull_request_branch` | ✅ (অর্থ "নতুন পরিবর্তন নামানো") |
| কোড খোঁজা, ইস্যু, রিভিউ | `search_code`, `search_repositories`, `list_issues`, `create_issue`, `create_pull_request_review` | ✅ |
| **ক্লোন** | কোনো `git clone` টুল নেই — শুধু ফাইল-বাই-ফাইল পড়া | ❌ |
| **ইনস্টল** (npm/pip/build) | রান করার কোনো উপায় নেই — GitHub MCP শুধু REST API | ❌ |
| **লোকাল এডিট + টেস্ট + রান** | ফোনের/সার্ভারের ফাইল ও শেল দরকার | ❌ (এখানে ফাইলসিস্টেম/SSH লাগবে) |

**সংক্ষেপে:** রিপো পড়া, লেখা, কমিট, পুশ, PR, মার্জ — সবই **হ্যাঁ**। কিন্তু "ক্লোন করে বিল্ড করে
টেস্ট চালিয়ে ফলাফল বলা" — এটা GitHub MCP নয়, এটা **শেল** (ফোনে Termux, বা VPS-এ SSH)।

## ২. "ফাইলসিস্টেম কনেক্টেড থাকলে আমার ফাইল পড়া/তৈরি করা যাবে?"

**হ্যাঁ, কিন্তু তিনটা শর্তে — আর এই তিনটাই এখনো বাকি কাজ:**

1. **স্কোপ**: অফিসিয়াল ফাইলসিস্টেম সার্ভার শুধু **অনুমোদিত ফোল্ডারের ভেতরে** কাজ করে
   (`list_allowed_directories` দিয়ে দেখা যায়)। টুলগুলো: `read_text_file`, `read_media_file`,
   `read_multiple_files`, `list_directory`, `directory_tree`, `search_files`, `get_file_info`,
   `create_directory`, `write_file`, `edit_file` (dryRun + git-style diff), `move_file`। **ডিলিট টুল নেই** —
   এটা নিরাপত্তার দিক থেকে ভালো।
2. **ট্রান্সপোর্ট**: এই সার্ভার ডিফল্টে **stdio** (শুধু প্রসেসের stdin/stdout)। আমাদের অ্যাপ **streamable
   HTTP** বোঝে। তাই মাঝখানে একটা ব্রিজ লাগবে (`supergateway`/`mcp-proxy`/`mcp-remote`)।
3. **কোন মেশিনের ফাইল?** — এটাই আসল প্রশ্ন। VPS-এ বসানো ফাইলসিস্টেম সার্ভার **VPS-এর ডিস্ক** পড়বে,
   আপনার ফোনের `/sdcard` নয়। ফোনের ফাইল পেতে হলে সার্ভারটাকে **ফোনেই** চালাতে হবে।

ফোনের ফাইলের দুটো পথ (পরের রিলিজে একটা বেছে নিতে হবে):

| পথ | কী লাগে | ভালো/খারাপ |
|---|---|---|
| **A. Termux-এ সার্ভার** | Termux + Node + `server-filesystem /sdcard/Documents` + stdio→HTTP ব্রিজ | আজই সম্ভব; কিন্তু Termux, Node, ব্যাটারি — ভঙ্গুর |
| **B. অ্যাপের ভেতরে SAF টুল-প্রোভাইডার** | শুধু অ্যাপ: ব্যবহারকারী SAF দিয়ে ফোল্ডার বেছে দেন, অ্যাপ নিজেই `read/list/search/write` টুল দেয় (লেখার আগে confirm) | Termux ছাড়া, ব্যাটারি-বান্ধব, নিয়ন্ত্রণযোগ্য — **সুপারিশ** |

## ৩. "`arshiyaazim/skills.git`-এর স্কিল কীভাবে কাজে লাগাবে?"

আমি রিপোটা দেখেছি (API দিয়ে, ১৪০ ফাইল, ৯টি `SKILL.md`, MIT): এটা **`base44/skills`-এর কপি** —
**Agent Skills** ফরম্যাট, **MCP নয়**।

```
skills/base44-cli/SKILL.md        ← YAML frontmatter: name, description + পুরো নির্দেশনা
skills/base44-cli/references/*.md ← বিস্তারিত রেফারেন্স, দরকার হলেই পড়া হয়
skills/base44-cli/scripts/*       ← python/node স্ক্রিপ্ট (চালাতে শেল লাগে)
.claude-plugin/plugin.json        ← marketplace ম্যানিফেস্ট
```

**মূল কথা: স্কিল = নির্দেশনা (prompt), টুল নয়।** স্কিল নতুন ক্ষমতা দেয় না; মডেল *যেভাবে* কাজ করবে
সেটা ঠিক করে দেয়। এখানেই আমাদের দুই স্তরের সুযোগ:

| স্তর | কী হয় | অ্যাপে কীভাবে |
|---|---|---|
| **১. প্রম্পট-স্তর** (এখনই সম্ভব) | GitHub zipball API দিয়ে রিপো নামানো (git লাগে না) → `SKILL.md`-র frontmatter থেকে সূচি → প্রশ্নের সাথে মিললে পুরো `SKILL.md` সিস্টেম-প্রম্পটে ইনজেক্ট ("progressive disclosure") | `skills/` লোডার + সেটিংস → স্কিল (রিপো URL, pinned commit, প্রতি-স্কিল অন/অফ) |
| **২. এক্সিকিউশন-স্তর** | `npx base44 create` ধরনের কমান্ড চালানো | Termux (ফোনে) বা VPS-এ SSH — শেল ছাড়া অসম্ভব |

সতর্কতা: **এই নির্দিষ্ট রিপো Base44-প্ল্যাটফর্মের জন্য** — আপনি Base44-তে অ্যাপ বানালে কাজে লাগবে,
নাহলে শুধু উদাহরণ। তাই বানানো উচিত **সাধারণ মেকানিজম**: যেকোনো Agent-Skills রিপো যোগ করা যাবে
(কমিট পিন করা, রিভিউ করে চালু, স্ক্রিপ্ট ছাড়া শুধু নির্দেশনা হিসেবে)।

## ৪. "SSH/VPS বলতে কী বুঝাচ্ছ? তুমি কি SSH/VPS-এ ঢুকতে পারবে?"

### ক. SSH মানে কী
SSH = Secure Shell, দূরের মেশিনে নিরাপদে কমান্ড চালানোর প্রোটোকল। অ্যাপে এর মানে হবে: **অ্যাপ = SSH
ক্লায়েন্ট** (sshj লাইব্রেরি), কী রাখা হবে Android Keystore-এ, কমান্ড **allowlist**-এ সীমিত, প্রতিটা
কমান্ড চালানোর আগে **আসল কমান্ডটা দেখিয়ে confirm**, আউটপুট টেক্সট/কণ্ঠে ফেরত। এতে VPS-এ
`git clone`, `npm install`, `docker compose up`, `apt` — সব সম্ভব।

### খ. আমি (এই অ্যাসিস্ট্যান্ট) কি আপনার VPS-এ ঢুকতে পারব?
**না, নিজে থেকে না।** আমার স্যান্ডবক্সে নেটওয়ার্ক আছে, `ssh` বাইনারিও আছে, কিন্তু **আপনার সার্ভারের কোনো
credential আমার নেই** — আর এই স্যান্ডবক্সে credential রাখা যায় না (প্রতিটা সেশনে মুছে যায়)। আপনি যদি
একটা সেশনে host + কী দেন, আমি *চেষ্টা করতে* পারি (আউটবাউন্ড ২২ পোর্ট খোলা কি না সেটাও যাচাই করা যায়),
কিন্তু সেটা **অ্যাপের ফিচার নয়** — আমার কাজের সুবিধা মাত্র।

### গ. "অ্যাপটা VPS-এ ওয়েব-অ্যাপ হিসেবে ইনস্টল করব?" — এটা ভুল আকৃতি
VoiceDock-এর শক্তি ঠিক সেই জিনিসগুলোতে যা **একটা ওয়েব পেজ কখনো পায় না**:

| ফিচার | ফোনের নেটিভ অ্যাপ | VPS-এর ওয়েব-অ্যাপ |
|---|---|---|
| accessibility (পড়া, লেখা, চুপচাপ পাঠানো) | ✅ | ❌ সম্পূর্ণ অসম্ভব |
| নোটিফিকেশন শোনা, সরাসরি রিপ্লাই | ✅ | ❌ |
| কল ধরা/দেওয়া (Telecom) | ✅ | ❌ |
| ফ্লোটিং বাবল, hotword "shahrukh" | ✅ | ❌ |
| SIM, MediaSession, on-device STT/TTS/Whisper | ✅ | ❌ |
| ক্যালেন্ডার/Gmail/Drive, GitHub, ফাইল, লম্বা কাজ | ✅ | ✅ |

অর্থাৎ **ওয়েব-অ্যাপ দিয়ে আপনার ডিভাইসে এজেন্টিক কাজ হবে না** — শুধু সার্ভারের কাজ হবে।

### ঘ. তাহলে সঠিক স্থাপত্য (যা আমি সুপারিশ করছি)

```
        ফোন (VoiceDock)                    VPS (সার্ভার)
   ┌──────────────────────┐          ┌──────────────────────────┐
   │ কান/মুখ: hotword, STT │  HTTPS   │ MCP সার্ভার: github,      │
   │ accessibility, কল,    │ ───────► │ filesystem(VPS), cron     │
   │ নোটিফিকেশন, বাবল      │  MCP     │ git clone/build/test      │
   │ ছোট কাজ নিজেই করে     │ ◄─────── │ docker, লম্বা জব          │
   └──────────────────────┘  JSON-RPC└──────────────────────────┘
        (আজ এটাই আছে)              (v1.5-এ যোগ হবে)
```
- **ফোন** = ইন্দ্রিয় ও কণ্ঠ, ডিভাইস-কাজ (আজকের অ্যাপ)।
- **VPS** = সর্বক্ষণের মস্তিষ্ক: যেখানে `git clone`, বিল্ড, টেস্ট, স্ক্রিপ্ট, স্কিলের স्क্রিপ্ট চলে।
- **সংযোগ** = MCP over HTTPS, কিন্তু পাবলিক নয় — **Tailscale/WireGuard/Cloudflare Tunnel** দিয়ে প্রাইভেট,
  আর Bearer টোকেন (আজকের কোডেই আছে)। ব্যাটারিও বাঁচে, কারণ ভারী কাজ ফোনে হয় না।
- **SSH** = যখন MCP-এ যা দরকার তার বেশি লাগবে (apt install, docker, সার্ভিস রিস্টার্ট) — allowlist + confirm সহ।
