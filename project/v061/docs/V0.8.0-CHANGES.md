# VoiceDock AI — v0.8.0 "knows my messages" (versionCode 15)

Phase 2 of the Jarvis plan. Needs **one new user-granted permission**: Notification access.

## What you can do now

Dictate, then **hold ⏎** (as in v0.7.0):

| You say | What happens |
|---|---|
| "আজ কে কে মেসেজ দিয়েছে?" / "summarise my messages" | a per-sender list of today's messages: name, count, last line — and it is read aloud if speech results are on |
| "শেষ ৫টা মেসেজ পড়ো" / "read my messages" | the last five messages with readable text are read out |
| "রহিমকে বলো আমি পরে ফোন করব" / "tell Karim I'll call later" | resolves the sender among today's notifications → confirmation card showing **name + exact text** → sends it from the notification's Direct Reply, WhatsApp never opens |

Failure paths are explicit, never silent:

* no notification access → the bubble says so and the **⚙** opens Settings → Commands;
* sender not found → offers the four most recent senders as buttons;
* two similar names ("রহিম উদ্দিন", "রহিমা") → both offered, you pick;
* the notification is gone → "…একবার খুলে দেখুন, তারপর আবার বলুন";
* the app did not offer a reply action → "এই নোটিফিকেশনে সরাসরি উত্তর দেওয়ার সুবিধা নেই — অ্যাপ থেকে পাঠাতে হবে";
* previews hidden → the digest says who wrote and when, **and states the text is hidden. It never invents a message.**

## What is stored, and what is not

| Stored (only while `নোটিফিকেশন থেকে পড়া` is on) | Never stored |
|---|---|
| sender name, app label, timestamp | screenshots or screen contents |
| message text **as the app chose to show it** (nothing if previews are off) | passwords, OTPs, keys |
| whether the notification offered a reply | anything uploaded — no network call exists in this path |

Kept in `notifications.json` (private app dir), capped at 400 rows, clearable from Settings → কমান্ড.
There is **no backfill**: Android gives no notification history, so the digest starts from the moment
access is granted — and the digest says "No messages today so far" rather than pretending.

## New code

```
notify/NotifEntry.kt          entry + JSON store (cap 400, upsert by key, "today" = local midnight)
notify/Digest.kt              pure grouping / wording / read-aloud / AI prompt (never invents text)
notify/SenderMatch.kt         Bangla-aware name matching ("রহিমকে" → "রহিম"), returns candidates
notify/RemoteReply.kt         Direct Reply via RemoteInput + live-notification registry (memory only)
notify/NotificationCapture.kt notification → entry, plus NotificationAccess status/settings intent
events/VoiceDockNotificationListener.kt   the real listener (was a v0.6 no-op)
command/CommandRegistry.kt    MSG_DIGEST / MSG_READ / MSG_REPLY now available; reply stays destructive
command/CommandParser.kt      reply + read sentences, checked BEFORE the call patterns
overlay/AssistantOverlayService.kt  digest / read / reply executors, sender resolution before confirm
ui/screens/CommandsSection.kt notification access status, grant + clear buttons, consent switch
```

## Deliberate choices

* **Reply resolution happens before the confirmation card**, so what you confirm is the real recipient
  and the exact text — not a name that gets resolved after you agreed.
* **The digest is computed on the device**, not by a cloud model. `Digest.aiPrompt` exists for a later
  opt-in "cloud summary" toggle; in v0.8.0 nothing from another app's notification leaves the phone.
* **Memory is still a JSON file.** v0.9 (`CallController`) is the natural moment to move memory + the
  notification log into Room in one migration, rather than doing two.

## Test on the phone (7 checks, in this order)

1. Settings → কমান্ড → "নোটিফিকেশন অ্যাক্সেস দিন" → enable VoiceDock in the Android list → the row must
   turn to ✓ and show a stored count that grows as messages arrive.
2. Ask a friend to message you in WhatsApp, then "আজ কে কে মেসেজ দিয়েছে?" → their name, count and last
   line, and no invented names.
3. Turn WhatsApp's message preview off, message again → the digest must say the text is hidden.
4. "রহিমকে বলো আমি পরে ফোন করব" → confirmation card shows **both** the name and the text → reject once,
   nothing must be sent.
5. Say yes → the message must arrive in the WhatsApp chat, and the bubble says "পাঠানো হয়েছে ✓".
6. Send a normal (non-command) dictation with a tap on ⏎ → still inserts as before.
7. Settings → "সংরক্ষিত সব মুছুন" → the stored count returns to 0.
