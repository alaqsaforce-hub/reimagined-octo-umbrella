# VoiceDock AI v1.3.4 — Calendar (read + add)

**Date:** 2026-11-01 · **Commit:** see git log · **APK:** `artifacts/VoiceDock-AI-v1.3.4-debug.apk` (vc 26, 1.3.4)

---

## What the user asked for

> "ক্যালেন্ডার দিয়েই শুরু কর" — start the remaining agent layer with the calendar.

So: **read** today / tomorrow / a named day / the coming week, and **add** an event from one spoken
sentence with a real resolved time. Bengali and English both. Nothing that could not be trusted.

## What was built

### `calendar/CalendarCore.kt` — every decision, no I/O

| Piece | Rule |
|---|---|
| `CalRange` | `TODAY`, `TOMORROW`, `WEEK`, `NAMED_DAY` |
| `range(word)` | "আজ/today" wins over everything; "সপ্তাহ/week" → 7 days; "কাল/কালকে/আগামীকাল/tomorrow" → tomorrow; a weekday name → that day; "পরশু" → the day after; otherwise today |
| `weekday(word)` | Bengali **and** English weekday names → `DayOfWeek` |
| `window(range, now, zone, word)` | Half-open `[from, to)` in the phone's zone. `NAMED_DAY` = the **next** occurrence of that weekday (today included), so "শুক্রবারের ক্যালেন্ডার" asked on a Sunday is the coming Friday, not today |
| `rangeLabel(...)` | Says the weekday back ("শুক্রবার (৬ নভেম্বর)"), not a vague "tomorrow" |
| `parseEvents(json)` | google-json lenient; **an event without a `summary` is dropped**, never shown as "(no title)"; missing `end` → start + 1 h; `start.date` ⇒ all-day |
| `createBody(...)` | Escaped JSON, `dateTime` + `timeZone` from the phone's zone, `location`/`description` only when non-blank |
| `list(events, label, bn)` | Empty list is a **real answer** ("আজ কোনো ইভেন্ট নেই।"), not an error; sorted, capped at 12 |
| `line(...)` | `• ০৯:৩০ — মিটিং (১ ঘণ্টা, অফিস)`; Bengali numerals when speaking Bengali |
| `durationLabel` | "১ ঘণ্টা ৩০ মিনিট" / "45m" |
| `draftText` | The confirmation card: **exactly** what will be booked, with the resolved time |
| `noTime` / `noTitle` | What to say when the sentence had no time or no title |
| `failure(reason)` | One honest sentence per `no_token`, `http_401`, `http_403`, `http_429`, `nonet`, `io`, `no_id` |

### `calendar/CalendarClient.kt` — the network half

- Google Calendar REST v3 against **`calendars/primary`** only.
- `list(from, to)` → `events.list?singleEvents=true&orderBy=startTime&timeMin&timeMax` (the recurring
  expansion is what makes "what's on today" correct for repeating events).
- `create(title, start, end)` → `events.insert`; **an event is only reported as added when the API
  returns an id**.
- Scope: `https://www.googleapis.com/auth/calendar.events` — read *and* add, and nothing more.
  The app never deletes, never edits, never invites an attendee, so no mail goes out by accident.
- The token is the **same in-memory token** `GoogleAuth` already issues for Gmail/Drive. It is cleared
  on restart, so `no_token` is a normal state with an honest sentence and a Settings hint — not a bug.

### Consent — the real gap this release closed

The calendar scope has to be granted where consent can happen: the Connectors screen. A new button
**"ক্যালেন্ডার যোগ করুন (পড়া ও নতুন ইভেন্ট)"** asks for **all three scopes in one consent**
(Drive read, Gmail read, Calendar events), because `GoogleAuth` keeps one token — asking for calendar
alone would have silently dropped the Gmail/Drive access the user had already granted. The screen
states, in Bengali, that the app only adds events and never deletes or edits.

`Skills.kt` no longer says the calendar is "planned: v1.3.0"; it is listed as available with its limit.

### Commands

| Sentence | Intent |
|---|---|
| "আজকের ক্যালেন্ডার দেখাও" / "what's on my calendar today" | `cal.list` |
| "কালকের ক্যালেন্ডার" / "এই সপ্তাহের ক্যালেন্ডার" / "শুক্রবারের ক্যালেন্ডার" | `cal.list` (range from the sentence) |
| "কাল ৩টায় ডাক্তারের অ্যাপয়েন্টমেন্ট ক্যালেন্ডারে যোগ করো" | `cal.add` (title + time) |

- The **calendar rule only fires when the sentence says ক্যালেন্ডার/calendar** — a reminder stays a
  reminder (there is a test that pins this).
- Title extraction removes the calendar words, the add verb (যোগ করো / ঢোকাও / লিখে রাখো / add to /
  schedule), filler and the exact time phrase `TimeWords` matched.
- Duration: "২ ঘণ্টা" / "৩০ মিনিট" when spoken, otherwise **one hour**.
- `cal.add` is **destructive → confirms** with the `draftText` card showing title, weekday, date and
  time before the request is sent. `cal.list` never confirms.
- No time in the sentence → `noTime` and **nothing is booked**. No title → `noTitle`. Both honest.

## What it deliberately does **not** do

- No deleting, editing, moving, or inviting. No secondary calendars, no calendar creation.
- No background sync, no notification for upcoming events (that is a later increment).
- Nothing is cached: every read is fresh, so a stale list can never be shown as current.

## Verified

- `assembleDebug testDebugUnitTest lintDebug` → **BUILD SUCCESSFUL**, **520 tests / 0 failed / 0 skipped
  / 71 suites**, lint **0 errors / 51 warnings**.
- 13 new tests (`app/src/test/java/com/voicedock/ai/v134/CalendarTest.kt`) — windows, weekday
  resolution, JSON honesty, request body escaping, empty-list honesty, failure sentences, grammar
  guards (reminder ≠ calendar), registry/confirmation wiring.
- One real product gap found by the tests and fixed: **"রিমাইন্ডারের তালিকা"** (the genitive form —
  the exact phrase the app's own help text suggests!) did not match any list marker and became
  `UNKNOWN`. `ReminderSpeech` now accepts it.

## Known limits (stated in-app)

- The token lives in memory: after a restart the user must reconnect before the first calendar read.
  The reply says so and points at Settings instead of failing silently.
- Bengali weekday names are matched as written; dialect spellings ("শুক্রবারের" vs "শুক্র") beyond the
  common forms fall back to today — the answer always names the date it read, so a wrong guess is
  visible rather than silent.
