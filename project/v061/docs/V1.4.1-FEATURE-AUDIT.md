## ২. কোনটা কিসের উপর দাঁড়িয়ে (গেটিং ম্যাপ)

### ক) সবসময় চালু (switch নেই)
- কমান্ড-পার্সার (offline) ও পাইপলাইনের ৫ ধাপ (বোঝা → সামর্থ্য → স্লট → কনফার্ম → চালানো)
- অনুমতি-প্রোব (`PermissionCatalog` + `ManifestAudit` টেস্ট)
- **MCP টুল-নীতি** (read-only হলে প্রশ্ন নেই, নাহলে প্রশ্ন)
- খসড়া-রক্ষা, undo-স্ট্যাক, ক্র্যাশ-লগ (শুধু debug বিল্ডে)
- গোপনীয়তা: API key/token Keystore-এ

### খ) শর্তসাপেক্ষ switch (আসল প্রভাব আছে)
| switch | কোথায় | কী বন্ধ হয় |
|---|---|---|
| `commandsEnabled` | Commands | **সব ৩৬টি ইন্টেন্ট** (শুধু ডিক্টেশন থাকে) |
| `mode` (৪টি) | মূল স্ক্রিন | ভয়েস ইনপুট, জোরে উত্তর, অভিবাদন |
| `speakResults` | সেটিংস | উত্তর শোনানো (১০ জায়গায় ব্যবহৃত) |
| `hotwordEnabled` / `hotwordAlwaysOn` / `hotwordLean` | Hotword | "shahrukh" জাগরণ; always-on ব্যাটারি মোড |
| `termuxEnabled` | Device | #22 Termux কমান্ড |
| `assistantBackgroundEvents` | Assistant | নোটিফিকেশন-ভিত্তিক সব ফিচার (#9–11, #16, #29) |
| `assistantScreenContext` / `assistantScreenshot` / `assistantAutoScan` | Assistant | স্ক্রিন পড়া, স্ক্রিনশট, স্বয়ংক্রিয় স্ক্যান |
| `cloudAllowed` / `localOnly` / `allowPaid` | AI | কোন প্রদানকারী ব্যবহার হবে |
| `crashLoggingEnabled` | Diagnostics | ক্র্যাশ-লগ |
| `mcpServers[]` | MCP | #34–35 (প্রতি সার্ভারে enabled switch) |
| `searchProvider` / `searxUrl` | Search | #17-এর সারমর্ম |
| `googleAccount` (+ মেমরি টোকেন) | Connectors | #32–33 |

### গ) ডেড / অর্ধেক switch (এখনই ঠিক করা দরকার)
1. **`taskUpdatesInBubble`** — v1.3.0-এ ঘোষিত "বাবে কাজের আপডেট", কিন্তু কোডে **একবারও পড়া হয় না**
   (০ usage) এবং UI-তেও switch নেই। অর্থাৎ **প্রতিশ্রুতি → বাস্তবায়ন নেই**।
2. `googleAccount` — শুধু দেখানোর জন্য (ঠিক আছে, কিন্তু টোকেন মেমরি-মাত্র)।
3. `assistantContacts` — পাঠানো হয় `contactsConsent`-এ; কাজ করে, কিন্তু শুধু এক পথে।
