# VoiceDock AI — v0.7.0 "understands me" (versionCode 14)

Phase 1 of the Jarvis plan (`docs/JARVIS-UPGRADE-PLAN.md` §6). Nothing here needs a new permission.

## What you can do now

Dictate as before, then **hold ⏎** instead of tapping it: the sentence is treated as a **command**
instead of text to insert. Tap ⏎ still inserts, exactly as in v0.6.7 — nothing changed for plain
dictation.

| You say | What happens |
|---|---|
| "হোয়াটসঅ্যাপ খোলো" / "open WhatsApp" | WhatsApp opens; the bubble says "WhatsApp খোলা হলো ✓" |
| "মনে রাখো কাল ৩টায় মিটিং" | saved to on-device memory: "মনে রাখলাম ✓ কাল ৩টায় মিটিং" |
| "আমি কাল কী মনে রাখতে বলেছিলাম?" | shows the stored notes that match (spoken too, if enabled) |
| "পড়ে শোনাও …" | Android TTS reads it; if the phone has no Bangla voice it says so instead of staying silent |
| "উফ কী গরম" (not a command) | asks "বুঝতে পারিনি — কী করতে চাও?" with 4 buttons; **never guesses** |
| "মাকে ফোন কর" | recognises `call.place`, then says it arrives in **v0.9.0** and offers "AI-কে জিজ্ঞেস করো" / "বাতিল" |

Settings → **কমান্ড (Jarvis)** shows the two switches, the memories (deletable one by one or all), and
the last commands with what was understood, by which route (`offline`/`model`) and whether it worked.

## How it decides (the part that matters)

```
sentence → offline patterns (always, no key, no internet)
         → only if they find nothing: the model, strict JSON, closed intent list
         → pipeline: not understood? → ask
                     not in this version? → say which version, offer alternative
                     missing a slot? → ask with ≤4 buttons (e.g. two WhatsApp apps installed)
                     destructive? → confirm once
                     otherwise → execute
```

Every step is pure Kotlin in `command/` and covered by **30 new unit tests** (`CommandLayerTest`, 271 total in
this build), so the safety rules are tested, not hoped for. Two real bugs were caught this way before
shipping: Java's `\p{L}` regex strips Bengali combining marks (every Bangla match was broken), and the
parser's digit normalisation was losing `৩` from stored memories.

## New code

```
command/CommandSpec.kt        Intent/Slot enums + strict CommandJson (fences, flat slots, unknown → null)
command/CommandRegistry.kt    required slots, destructive flag, available flag (v0.8/0.9/0.10 intents are
                              recognised but marked unavailable so no phase can pretend)
command/CommandParser.kt      Bangla+English offline patterns, normalisation, the model prompt
command/CommandPipeline.kt    the 5-step decision + human-readable describe()
command/CommandLog.kt         local ring buffer (50) of raw → intent → strategy → result
memory/MemoryStore.kt         JSON file (not Room: no migration risk for an existing install), 300 cap
memory/MemoryText             pure search + wording ("never invent")
appc/AppLauncher.kt           name → package matching with Bangla aliases, launch intent
tts/Speaker.kt                TextToSpeech wrapper with bn-BD → en-US fallback
ui/screens/CommandsSection.kt Settings section (switches, memories, log)
overlay/DictationBubble.kt    + choice buttons (≤4), ⏎ = tap insert / hold command
overlay/AssistantOverlayService.kt  runCommand/handleCommand/onChoicePicked/executeCommand
```

## Deliberate deviations from the plan, and why

* **No `QUERY_ALL_PACKAGES`.** The manifest already declares a `<queries>` intent for
  `MAIN`/`LAUNCHER`, which is enough to list launchable apps. `QUERY_ALL_PACKAGES` is a sensitive
  permission Play restricts, and the app does not need it. (Plan §7 listed it; this is stricter.)
* **Memory is a JSON file, not Room** in this phase — an existing install has a Room database and a
  new entity means a migration; the store is capped at 300 entries and moves to Room in v0.8 together
  with `NotifStore`, when a migration is needed anyway.
* **`CALL_*`, `MSG_*`, `MEDIA` are recognised but unavailable.** They are parsed and explained, never
  silently ignored and never faked. The table in `CommandRegistry` is the single switch each phase flips.

## Test on the phone

1. Floating icon → say "হোয়াটসঅ্যাপ খোলো" → **hold ⏎** → WhatsApp opens, card says ✓.
2. Say "মনে রাখো কাল ৩টায় মিটিং" → hold ⏎ → saved; check Settings → কমান্ড lists it.
3. Say "আমি কাল কী মনে রাখতে বলেছিলাম?" → hold ⏎ → the note comes back (and is spoken).
4. Say "উফ গরম আজ" → hold ⏎ → 4 buttons appear, nothing happens by itself.
5. Tap ⏎ (no hold) with normal text → still inserts into the host app, unchanged.
